03 / SECURITY PRIMITIVES

Designed for agents that can
reason around instructions.

01

Agent Passport

Cryptographically verifiable identity and principal binding.

02

Mission Boundary

Authority exists for a declared purpose and expires with it.

03

Capability Tokens

Short-lived, scoped, revocable authority—not raw credentials.

04

Intent Firewall

Detect actions that no longer align with the authorized mission.

05

Escape Detection

Signals for sandbox probing, privilege discovery, and exfiltration.

06

Blind Secrets

Perform authenticated work without revealing credentials to models.

07

Delegation Guard

Child authority remains a strict subset of parent authority.

08

Economic Guard

Bound money, tokens, API consumption, cloud spend, and resources.

09

Flight Recorder

Replay structured actions without collecting private chain-of-thought.

07 / INTEGRATE IDENTITY

Three steps to become agent-aware.

1Verify

Validate signature, expiry, issuer, and revocation.

2Authorize

Evaluate mission and capability against platform policy.

3Enforce

Allow, limit, challenge, quarantine, or deny at the boundary.

Platform middleware — TypeScript
import { AgentGuardClient } from "@cairo/agentguard";

const guard = new AgentGuardClient("http://127.0.0.1:8787");
const decision = await guard.authorize(agentRequest);

if (!["ALLOW", "ALLOW_WITH_LIMITS"].includes(decision.effect)) {
  throw new Error(`Blocked by Agent Guard: ${decision.reason}`);
}
